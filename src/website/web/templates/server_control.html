Server control

Start, stop and restart the game server, and read its live log. Every action goes through server_manager on the game host and is written to the Staff Log with your reason.

{{if not .Configured}}

server_manager isn't connected

The website controls the game server through server_manager's control API. To connect it, copy ControlAPIToken from server_manager's settings.json and set these in the website's environment, then restart the website:

SERVER_MANAGER_URL=http://127.0.0.1:8095
SERVER_MANAGER_TOKEN=<ControlAPIToken>
